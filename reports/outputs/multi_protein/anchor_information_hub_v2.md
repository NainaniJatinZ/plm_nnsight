# Anchor Information-Hub Experiment v2

## Methodology

Tests whether anchors are information hubs using top-1 and top-3 anchors against structurally matched controls.

Three target sets: G1 (random distant, n<=16), G2 (task-relevant SS1/SS2 segments), G3 (distant 3D contacts, CB < 8A, |i-j| >= 24).

Summary metrics: mean_influence, top25_mean (top quartile mean), max_influence, fraction_positive.
