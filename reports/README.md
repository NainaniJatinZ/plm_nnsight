# Interactive Attention & Contact Map Visualization

## Overview

This directory contains an interactive HTML visualization tool for exploring ESM2 attention patterns and contact predictions in the contact jump analysis.

## Files

- `attention_viz.html` - Standalone interactive viewer (open in browser)
- `viz_data.json.gz` - Exported attention and contact data (generated by `contact_jump.py`)

## Usage

### 1. Generate Visualization Data

Run the contact jump analysis to export visualization data:

```bash
# Run the contact_jump.py notebook (or individual cells)
python contact_jump.py  # If running as script
# OR open in Jupyter/VSCode and run cells
```

This will create `reports/viz_data.json.gz` containing:
- Top 100 attention heads sorted by effect magnitude
- Full attention matrices (379×379) for each head
- Contact maps (clean, corrupt, original)
- Protein metadata and sequences

### 2. Open Visualization

Simply open `attention_viz.html` in a web browser:

```bash
# On local machine
open reports/attention_viz.html  # macOS
xdg-open reports/attention_viz.html  # Linux

# On remote server via SSH
# Option 1: Copy to local machine
scp user@server:/path/to/reports/{attention_viz.html,viz_data.json.gz} ~/Downloads/

# Option 2: Use SSH port forwarding + Python server
cd reports
python -m http.server 8000
# Then browse to http://localhost:8000/attention_viz.html
```

## Features

### Viewing Modes

- **Clean**: Show attention and contacts for clean sequence (larger flank)
- **Corrupt**: Show attention and contacts for corrupt sequence (smaller flank)
- **Diff**: Show difference (clean - corrupt) with diverging colormap

Keyboard shortcuts: `C` (clean), `R` (corrupt), `D` (diff)

### Layout

```
┌─────────────────────────────────────────────────────────┐
│ Header: Layer, Head, Effect, Mode Toggle                │
├──────────────────────────┬──────────────────────────────┤
│ Attention Region 1→2     │ Contact Map (full 379×379)   │
│ (left_flank + ss1 rows)  │                              │
│ (ss2 + right_flank cols) │                              │
│                          │                              │
│ Attention Region 2→1     │ Info Panel:                  │
│ (ss2 + right_flank rows) │ - Hover values               │
│ (left_flank + ss1 cols)  │ - Metrics                    │
│                          │ - Region controls            │
│                          │ - Color legend               │
├──────────────────────────┴──────────────────────────────┤
│ Head Selector: [L26H16] [L22H14] [L32H13] ...           │
└─────────────────────────────────────────────────────────┘
```

### Interactions

- **Hover**: Show position and value for each cell
- **Click**: Select cell (future: synchronized highlighting)
- **Mouse wheel**: Zoom in/out (1.0x - 20.0x)
- **Head selector**: Click tabs to switch between heads
- **Keyboard**: Arrow keys to navigate heads, 1-9 for top heads

### Region Controls

Adjust the displayed attention regions:

- **Region 1**: Left flank + ss1 segment
  - Default: positions [133:188] for clean (flank=44)
- **Region 2**: ss2 segment + right flank
  - Default: positions [311:366] for clean (flank=44)

**Presets**:
- **Segments Only**: Just the ±5 residue windows around contact pair
- **Clean Flanks**: Default, uses clean_flank=44
- **Corrupt Flanks**: Uses corrupt_flank=43
- **Custom**: Manually adjust start/end positions

### Color Scales

- **Attention (clean/corrupt)**: Viridis (purple → blue → green → yellow)
  - Range: 0.0 (no attention) to 1.0 (max attention)
- **Diff mode**: RdBu (red → white → blue)
  - Range: -1.0 (corrupt higher) to +1.0 (clean higher)

## Data Export Details

### Export Script

The export is handled by `export_viz_data.py`:

```python
from export_viz_data import export_visualization_data

export_visualization_data(
    clean_attn_LBHLL=clean_attn_LBHLL,           # List of 33 attention tensors
    corrupt_attn_LBHLL=corrupt_attn_LBHLL,       # List of 33 attention tensors
    effects_LH=effects_LH,                       # (33, 20) effect matrix
    clean_contacts_AA=clean_contacts_AA,         # (379, 379) contact map
    corrupt_contacts_AA=corrupt_contacts_AA,     # (379, 379) contact map
    orig_contacts_AA=orig_contacts_AA,           # (379, 379) contact map
    segment=segment,                             # ContactSegment dataclass
    sequences={'full': ..., 'clean': ..., 'corrupt': ...},
    protein="2B61A",
    config=PROTEINS["2B61A"],
    output_path="reports/viz_data.json.gz",
    top_k=100  # Export top 100 heads only
)
```

### Data Format

The exported JSON structure:

```json
{
  "metadata": {
    "protein": "2B61A",
    "seq_length": 379,
    "segment": {"ss1_start": 177, "ss1_end": 188, "ss2_start": 311, "ss2_end": 322},
    "clean_flank": 44,
    "corrupt_flank": 43,
    "clean_metric": 0.5740,
    "corrupt_metric": 0.0280
  },
  "sequences": {
    "full": "MKTF...",
    "clean": "MKTF...<mask>...",
    "corrupt": "MKTF...<mask>..."
  },
  "heads": [
    {
      "layer": 26,
      "head": 16,
      "effect": 0.2940,
      "clean_attn": {"0": {"5": 0.0012, ...}, ...},    // Sparse format
      "corrupt_attn": {"0": {"5": 0.0008, ...}, ...}
    },
    // ... 99 more heads
  ],
  "contacts": {
    "clean": {"0": {"0": 0.95, ...}, ...},
    "corrupt": {"0": {"0": 0.92, ...}, ...},
    "original": {"0": {"0": 0.98, ...}, ...}
  }
}
```

### Sparse Encoding

Matrices are stored in sparse format to reduce file size:

- **Dense**: 379×379 = 143,641 floats = 574 KB per matrix
- **Sparse**: Only non-zero entries (~10% = 14,364 entries) = 57 KB per matrix
- **Compression**: ~10x reduction before gzip, ~50-100x after gzip

Sparse format: `{row: {col: value}}` with 4 decimal precision.

## File Sizes

Expected sizes for 2B61A (seq_length=379, top_k=100):

- **Uncompressed JSON**: ~150 MB
- **Compressed (.json.gz)**: ~10-50 MB
- **HTML viewer**: ~30 KB

## Troubleshooting

### "Failed to fetch viz_data.json.gz"

The HTML file looks for `viz_data.json.gz` in the same directory. Make sure both files are in the same folder.

### "Mixed Content" warning

If loading over HTTPS, ensure the data file is also served over HTTPS. Use a local file:// URL or set up a local web server.

### Slow performance

- Reduce `top_k` in export (e.g., 50 instead of 100)
- Use a smaller protein (shorter sequence = smaller matrices)
- Try a different browser (Chrome usually fastest)

### Empty/black matrices

Check browser console for errors. Common issues:
- Data file not found (wrong path)
- Gzip decompression failed (corrupted file)
- JSON parse error (invalid format)

## Development

To modify the visualization:

1. Edit `attention_viz.html` (all code is embedded)
2. Refresh browser to see changes
3. Use browser DevTools console for debugging

Key modules in HTML:
- `DataManager`: Load and decode JSON.gz
- `RegionExtractor`: Extract submatrices from full attention
- `MatrixRenderer`: Canvas-based rendering with zoom/pan
- `App`: Main application state and coordination
