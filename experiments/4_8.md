

The highest-value experiment is still the remote-homolog / same-fold test.

Here is why.

A strong structure-based result should transfer across proteins that have **similar structure but low sequence identity**. A pure sequence-identity or family-column lookup story should break much more badly there.

A practical operationalization already exists in the literature: “remote homology pairs” are commonly defined as sequence identity below 0.3 with TM-score above 0.5, and TM-score above 0.5 is widely used as a rough same-fold threshold. Foldseek is built exactly for fast structure search, and it can realign hits with TM-align-style alignment.

### What to do

For each protein with a clear anchor:

1. Use Foldseek to find proteins with similar structure but low sequence identity.
2. Keep a stricter subset too, maybe TM-score above 0.6 and seqid below 0.25, for the “hard” analysis.
3. Structurally align the pair.
4. Map the anchor residue in protein A to the aligned residue in protein B.
5. Ask:

- Is the aligned position in B also high in anchor score or top-k rank?
- Is this transfer stronger under structural alignment than under sequence alignment?
- Do aligned anchor sites match better than matched buried non-anchor controls?
- Does the transfer survive across different families within the same fold, or only within near-homologs?

### Why this is so valuable

This one experiment separates three stories:

- **If the aligned structural site stays anchor-like even at low sequence identity**, that is real evidence for a structure-linked landmark detector.
- **If anchorhood follows HMM columns only within close family**, that looks more like family memory or motif lookup.
- **If neither transfers well**, then the anchor may be a local per-protein integration score, not a fold-stable landmark.

Any of those outcomes gives you a paper direction. That is why I like this experiment so much.

## The second decisive experiment

Do not run fifty more feature sweeps.

Run one brutal control:

**true-SSE blocks vs predicted-SSE blocks vs random matched blocks**

Your current scramble result is suggestive, but not fully isolating geometry. The clean control is:

- scramble within true SSE segments
- scramble within predicted SSE segments, predicted from sequence only
- scramble within random contiguous blocks matched for block lengths

Interpretation:

- If true and predicted SSE both preserve the signal, but random blocks do not, that is strong evidence the model relies on **sequence-inferable structural organization**
- If true SSE works but predicted SSE does not, the perturbation may be injecting structure information the model itself does not actually infer
- If random matched blocks also work, then your current result is more about coarse block preservation than SSE geometry

That experiment is cheap relative to its value.

## The third experiment, but keep it tight

You probably need exactly one clean causal path figure:

**MLP9 → anchor direction ddd → L10H9 selection → downstream interaction heads**

Not a huge circuit zoo. One path.

What I want from this figure is not every upstream head. I want one answer:

> Does removing the MLP9-written component along ddd specifically weaken anchor selection and the relevant downstream contact readout more than matched controls do?

If yes, you have a real mechanism.  
If not, the MLP story is still descriptive.

Here is the thesis I think has the best chance of being true and clean:

**L10H9 is a universal structural-landmark selector. It uses local sequence context to infer which residue is most structurally integrative, then downstream contact heads use that landmark as a routing primitive for pairwise reasoning.**

That is not “just sequence identity.”  
That is not “the whole model does geometry here.”
