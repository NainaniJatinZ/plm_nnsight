## Discussion 4/4 — what gets us to a paper

### The real problem
Without identifying what d detects, there is no paper. Everything else is scaffolding. The "so what" requires knowing the feature.

### Option 1: Flank counterfactual + upstream attention head discovery
**Setup:** small flank (anchor absent) vs large flank (anchor present) as clean/corrupted pair. Path-patch or activation-diff at earlier layers to find which heads change their contribution to the anchor position.

**Possible outcomes:**
- **(A) Reused upstream heads exist** — a class of heads consistently changes behavior between small and large flank. Then the investigation shifts to interpreting THOSE heads. This is progress but opens a new interpretation task. Prior contact circuit work found upstream heads were LESS reused than L10H9 itself, so this is not guaranteed.
- **(B) MLPs are the main upstream contributor** — the anchor feature is written by MLPs, not attention. Would need to interpret MLP internals (top-activation analysis over many proteins, or use neuron2graph-style methods). Recent work (e.g., Gurnee et al.) suggests MLP neurons can be monosemantic but this is a significant interpretation effort.
- **(C) No single globally reused upstream component** — different proteins use different heads/MLPs. Could be protein-family-specific or fold-specific. This is the most likely outcome given prior experience, and the hardest to turn into a clean story.

**Time cost:** moderate. Two forward passes per protein, activation capture, ranking. The experiment itself is fast. The interpretation of results could be expensive.

**Key risk:** even if we find upstream heads, we still need to say what they compute. The task cascades.

### Option 3: Clustering on inputs to the search direction
**Idea:** cluster the layer-10 LN residuals at anchor positions. Maybe project onto d and look at what’s orthogonal, or cluster the full vector. Now that we know it’s motif-level, maybe cluster on the flank windows rather than single-residue features.

**Problem with naive clustering on x:** trivially groups similar proteins together. The representation at layer 10 is highly protein-specific. You’d rediscover protein families.

**Could cluster on:** 
- projection onto d (scalar — not much to cluster)
- r_i (orthogonal residual) — this was done in anchor_subtype_discovery. PCA explained only 28.8% variance in 30 components. HDBSCAN found 3 clusters but one had 986/1050 anchors. Model-space and structure-space clusters had near-zero agreement (ARI = -0.025). Basically: r_i is high-dimensional noise without clean structure.
- flank sequence windows — but the flank classifier already showed this doesn’t separate anchors from matched controls with handcrafted features

**My honest assessment:** the previous clustering on r_i was uninformative. Clustering on flanks would face the same problem as the flank classifier — once you control for burial, there’s no obvious static pattern. The "motif" the model uses is probably a learned nonlinear function of the local context, not something that clusters nicely in input space.

### The circular problem
We want to know the question (what d detects) but can’t figure it out without knowing the answers (what makes anchors special). And the answers are "structurally integrative, not just buried, not a simple motif." The feature seems to be a genuinely novel learned concept that doesn’t reduce to known structural descriptors.

### What would actually make a paper?

**Uncomfortable truth:** if we can’t name the feature, we need a different kind of contribution.

Possibilities:
1. **The feature IS the contribution** — "ESM2 has learned a structural-integration concept that is not reducible to known structural descriptors." This is surprising IF we can show it rigorously. The matched-control analysis already argues this. The flank jump shows it’s computable from local context. The universality shows it’s not a protein-specific artifact. Maybe the paper is: "here is a new structural concept that a protein language model invented, and here’s everything we can say about it." This is honest but needs to be framed carefully.

2. **Utility as contribution** — if d identifies structurally important residues that existing methods miss, that’s useful. Can we show d-score predicts something that RSA/contact-count/betweenness/closeness don’t? Mutation sensitivity? Thermostability? Allosteric sites? This turns the unknown feature into a practical tool.

3. **Upstream circuit as contribution** — if we do find clean upstream structure, the circuit itself (local context → upstream heads → anchor feature → interaction heads → contacts) is a mechanistic story about how PLMs process local motifs into global structure predictions. Even without naming the feature, the circuit architecture is the finding.

### Script audit note
The local flank v2 script has issues (see separate audit). SSE-only controls are inflated. Structural controls are underpowered (n=17). The negative result is probably right but not rock-solid. If we want to publish the "no simple motif" claim, we should re-run with more structurally matched proteins.

## Decision 4/4 — three experiments to run

### On whether Path 1 is NeurIPS-worthy
Reviewer hat: "they found a universal monosemantic head in ESM2 and showed it detects a novel structural concept not reducible to known descriptors" — yes, this is interesting IF the evidence is airtight. The novelty is that a PLM has *invented* a structural concept. That's a statement about what masked language modeling learns about protein structure, which is a live question in the field. But every claim needs to be solid: the "not reducible" claim needs more than 17 proteins. The universality needs rigorous controls. And ideally we'd have SOME handle on the feature, even if we can't name it cleanly.

### Experiment 1: Better flank classification (fix the "no simple motif" claim)

**Problems with v2:**
- SSE-only controls (500 proteins) are too weak — classifier exploits burial proxies
- Structural controls (17 proteins) are too few — results are noisy noise
- At large R, feature dims >> samples for structural set
- Need to confirm the negative result OR discover a real motif

**Improvements:**
- Compute RSA + contacts_8A for ALL 500 high-confidence proteins from PDBs (they're from PDB-based dataset, structures should exist)
- This gives us structurally matched controls at scale (500 proteins instead of 17)
- Two approaches to the dimensionality problem:
  - (a) **Feature families separately**: run seq-only, SSE-only, structural-only, then combined. This lets us see which feature type (if any) carries signal without drowning in dims
  - (b) **Summary features only at large R**: drop per-position one-hot features when R > 15, keep only summary stats (counts, hydrophobicity profiles, transition counts). This keeps feature dims manageable.
  - (c) **Alternatively**: use a fixed set of biologically motivated summary features at all radii. Something like: hydrophobicity profile (binned into left/right/center thirds), SSE transition count, SSE composition, AA class composition. ~30-50 features total, interpretable, stable across radii.

**What we learn:**
- If signal appears at scale → there IS a motif, we missed it with 17 proteins
- If signal stays dead at scale → "no simple motif" is rock solid and publishable
- Either way, we have a clean result

**Estimated time:** moderate. PDB feature extraction is the bottleneck (probably have most of it from the audit already?). Classification code exists, just needs better controls and feature design.

### Experiment 2: Upstream circuit (what builds the anchor feature?)

**Setup:** Use the flank counterfactual — small flank (e.g., R=5, anchor signal absent) vs large flank (e.g., R=30, anchor signal present).

**Method:** For each protein, two forward passes. At the anchor position, decompose the CHANGE in d-projection into contributions from each component (attention head OV outputs + MLP outputs, layers 0-9). This is direct logit attribution / contribution analysis to the search direction — standard method (Logit Lens / contribution decomposition, used in Elhage et al., etc).

For each layer l and head h:
```
delta_contrib[l,h] = (attn_out_largflank[l,h,anchor] - attn_out_smallflank[l,h,anchor]) · d
```
Same for MLPs. Then rank and do overlap analysis across 100-500 proteins.

**Possible outcomes:**
- (A) Reused attention heads → investigate those heads next (task cascades but we learn circuit structure)
- (B) MLPs dominate → harder to interpret but tells us it's a "knowledge retrieval" pattern
- (C) Family/fold-specific upstream heads → interesting finding about how PLMs organize structural knowledge, even if harder to interpret per-head
- (D) No clean pattern → negative result, still informative

For outcome (C): this IS a finding. "The anchor feature is universally detected by one head, but constructed by family-specific upstream circuits" says something real about PLM architecture. Universal readout, diverse computation.

**Estimated time:** fast to run. 2 forward passes × N proteins. Analysis is ranking + overlap computation. Interpretation could be slow if we find reused heads.

### Experiment 3: Better motif clustering / feature analysis

**The insight:** previous clustering on r_i was wrong because r_i is the ORTHOGONAL component — it captures protein-specific variation, not the universal question. Alpha (projection onto d) is just a scalar. Neither is the right thing to cluster.

**What we actually want to cluster:** what in the INPUT (the flank) contributes to high alpha? The model computes alpha from ~50 residues of local context. Which positions matter, and is there a pattern?

**Concrete approach — per-position importance maps:**
For each anchor with its full flank, mask one flank position at a time and measure the drop in alpha. This gives an importance curve I(j) over the ±30 window for each protein. These importance curves CAN be clustered — they're fixed-length, comparable across proteins, and they capture what the model actually uses.

Cost: ~60 forward passes per protein (mask each position in ±30). For 100 proteins that's 6000 forward passes — feasible.

If the importance curves cluster:
- By fold/family → the model uses family-specific local signals for a universal readout
- By structural motif (e.g., "strand-loop-strand" vs "helix-turn-helix") → the model recognizes structural context types
- No clustering → the model uses each flank in a unique way (harder to interpret)

**Alternative approach — attention from upstream heads as a proxy for position importance:**
If Experiment 2 reveals specific upstream heads, look at their attention patterns. Which flank positions do they attend to when writing to the anchor? This is cheaper than leave-one-out masking and gives similar information.

**What about clustering flank sequences directly?**
Risky. Raw flank sequences will cluster by protein family, not by structural property. Could partially address this by:
- Representing flanks as AA-class sequences instead of raw AA
- Aligning by SSE (e.g., "X residues into the current strand" as a coordinate system)
- But this gets complicated fast and may not help

**My ranking for Experiment 3 sub-options:**
1. Per-position importance maps (cleanest, directly answers "what matters in the flank")
2. Upstream attention patterns (cheaper, but dependent on Exp 2 results)
3. Flank sequence clustering (least likely to work)

### Execution order
1. **Experiment 2 first** — fastest to run, highest information gain. The decomposition directly tells us heads vs MLPs, reused vs not. And if we find reused upstream heads, their attention patterns give us Experiment 3 for free.
2. **Experiment 1 second** — needs PDB feature computation at scale, but firms up the "no simple motif" claim either way.
3. **Experiment 3 (importance maps) if needed** — only if Experiments 1-2 don't give us enough to characterize the feature.

### What would a paper look like if all three work out?

**Best case narrative:** "ESM2 uses a universal anchor head (L10H9) to identify structurally integrative residues via a single search direction. The anchor feature is built from local context (±25 residues) by [upstream circuit structure from Exp 2]. The feature is not reducible to known structural descriptors [Exp 1 at scale] but captures [pattern from Exp 3 importance maps]. This reveals how PLMs convert local sequence motifs into global structural representations."

**Minimum viable paper (if Exp 3 gives nothing):** "ESM2 has a universal monosemantic head that detects a novel structural concept. We characterize the detection mechanism, its local context dependence, and its upstream circuit. The detected feature is genuinely new — not burial, not a static motif, not in existing structural vocabularies."

## Experiment 1 results (4/5 morning)

### Major revision: there IS a partial motif
The v2 "no simple motif" conclusion was a **sample size failure** (n=17), not a real negative. Artifact check confirmed: H1 SSE-only (0.291) ≈ H1 structural (0.295) on same 285 proteins. The SSE-only controls were NOT inflating results.

### Results table

| Model | Matching | AUPRC | vs Base Rate |
|---|---|---|---|
| H4 (3D structural) | structural, 285 prot | 0.418 | 2.5x |
| H4 without center | structural | 0.399 | 2.4x |
| H2 (SSE arrangement) | SSE-only, 500 prot | 0.394 | 2.4x |
| H3 (physicochemical) | SSE-only, 500 prot | 0.382 | 2.3x |
| H1 (AA identity) | SSE-only, 500 prot | 0.320 | 1.9x |
| H5 (positional) | SSE-only, 500 prot | 0.182 | ~1x (null) |
| FULL (L1) | SSE-only, 500 prot | 0.413 | 2.5x |
| FULL (GBT) | SSE-only, 500 prot | 0.630 | 3.8x |

Permutation test H4: p=0.000 (null 95th pctl: 0.192).

### Key findings

1. **H4 is strongest individual predictor.** Flank structural context — per-position RSA, contact-with-center, long-range fraction — predicts anchorhood under proper matching. Center RSA coefficient (+20) was a regularization artifact; removing it drops AUPRC by 0.001. Flank-only (no center features) still 2.4x base rate.

2. **Top H4 flank features:**
   - RSA at positions -1, +2, +3, +4, +9 (burial pattern around anchor)
   - contact-with-center at -4, -1, +6 (3D proximity of flank to center)
   - Long-range fraction at -3, -15, -23, -24 (hub-like neighbors)

3. **GBT >> L1 (0.630 vs 0.413).** Strong nonlinear interactions across feature families. Top GBT features: center hydrophobicity (0.111), position within SSE (0.070), coil at +1/+2, hydrophobicity at -1, fractional position and distance to C-terminus.

4. **H5 null alone but important in GBT interactions.** Positional context matters only in combination with local sequence/structure.

5. **R=15 ≈ R=30 for H1-H3.** Discriminating features are available locally. But the model needs ±25 (flank masking). Gap means the model computes something richer than these static descriptors.

### Interpretation: what d detects (partial answer)

Anchors are at positions where the **local structural neighborhood** is densely connected:
- The surrounding ±15-30 residues are buried (low RSA)
- Multiple flank positions are in 3D contact with the center
- Flank positions are themselves structurally hub-like (high long-range fraction)
- The center sits at an SSE junction (coil at +1/+2) with specific hydrophobicity

This isn't just "the center is buried" (that's matched for). It's "the center is in a dense structural cluster where the neighborhood is also structurally integrative." The model needs ±25 residues to compute this because it's detecting the cluster topology, not any single feature.

The static descriptors capture ~63% of the discriminability (GBT), meaning ~37% of what the model computes is beyond these features. The model's nonlinear computation over the flank extracts something richer.

### What this changes for the paper

We went from "we can't explain what d detects" to "d partially detects local structural neighborhood density, with a nonlinear component we can characterize but not fully reduce to handcrafted features." That's a much stronger story.

## Experiment 2 results (4/5)

### Two metrics tell different stories — both are real

**Analysis 1 (signed fraction):** MLPs dominate. mlp_L9 = 52%, mlp_L8 = 26%. MLPs push consistently in the anchor direction (sign consistency 88%).

**Analysis 2 (absolute budget):** Attention = 65.8%, MLP = 34.1%. Attention heads contribute MORE total magnitude, but in BOTH directions — many push toward anchoring, others push against. Cancellation.

So: attention heads are noisy gatherers (lots of activity, partial cancellation). MLPs are consistent builders (less raw magnitude but always in the right direction).

### Recurrence vs sign consistency (important correction)

| Head | Recurrence top-10 | Sign consistency | Interpretation |
|---|---|---|---|
| L9H3 | 86% | NOT in top-20 signed | Large |delta| but direction flips — active but inconsistent |
| L9H9 | 72% | 52% | Same — large effect but near-random sign |
| L8H6 | 62% | NOT in top-20 signed | Active but inconsistent |
| L9H8 | 56% | 88% | Both recurrent AND consistent — reliable contributor |
| L9H13 | 30% | 86% | Less recurrent but very consistent |
| L8H11 | 8% recurrence | 86% | Consistent but not widespread |

The most RELIABLE upstream attention heads are L9H8 and L9H13 (recurrent + sign-consistent). L9H3 is the most ACTIVE but flips sign — it's doing something important but not always in the anchor direction.

### MLP dominance

The core story: MLPs L6-L9 are the main builders. They consistently push the anchor feature in the right direction. This is consistent with MLPs being the "recognizer" — they take the gathered context and apply a nonlinear transformation to produce the anchor feature. This aligns with Exp 1's finding that GBT >> L1: the feature involves nonlinear pattern recognition.

### Layer profile
Layer 9 dominates (total delta 6.81), followed by 8 (2.39) and 7 (2.27). Built incrementally L6→L9.

Interesting: L8 attention is net NEGATIVE (-1.03) while L8 MLP is strongly positive (3.42). The attention heads at L8 are actively pulling away from the anchor direction on average, and the MLP compensates.

### Sanity check
Pre-LN vs post-LN: r=0.81, rho=0.83. Post-LN/pre-LN ratio: mean 0.11, std 0.02. LN compresses magnitudes ~9x but preserves ranking approximately. Good enough.

### Jaccard clustering
Mean pairwise Jaccard = 0.229 (moderate). Visual inspection of heatmap shows some apparent clusters but manual checking of first 3 didn't reveal clean groupings. Not pursuing further for now.

### Circuit summary
```
flank (±25 residues) 
  → L7-L9 attention heads gather context to anchor position 
     (noisy, partially canceling; L9H8 and L9H13 most reliable)
  → L6-L9 MLPs recognize structural pattern, consistently write anchor feature
     (MLP_L9 = 52% of total signed delta)
  → L10H9 reads via universal search direction d
```
